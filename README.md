# منظومة دلالة التجارية — Dalala Commerce

منظومة حديثة لإدارة المحلات والشركات التجارية: **نقطة بيع، مخزون، مشتريات، حسابات العملاء والموردين، خزينة، مصروفات وتقارير أرباح** — بواجهة عربية/إنجليزية، متوافقة مع ليبيا (الدينار الليبي، السجل التجاري، الرقم الضريبي، الغرفة التجارية)، وتعمل بدون إنترنت على ويندوز أو المتصفح.

A modern, bilingual (Arabic / English) point of sale, inventory and accounting system for shops and trading companies, set up for Libya.

## التشغيل — Getting started

- **ويندوز:** شغّل `Dalala-Commerce-Setup-<version>.exe` (يُبنى تلقائياً عبر GitHub Actions، أو محلياً — انظر أدناه).
- **المتصفح:** افتح `index.html` أو شغّل خادماً محلياً: `python3 -m http.server 8080`

| الدور / Role | اسم المستخدم | كلمة المرور |
|---|---|---|
| مدير النظام / Admin | `admin` | `admin123` |
| كاشير / Cashier | `cashier` | `cashier123` |
| محاسب / Accountant | `accountant` | `acc123` |
| أمين مخزن / Storekeeper | `store` | `store123` |

تبدأ المنظومة ببيانات تجريبية واقعية (37 صنفاً، 10 عملاء، 6 موردين، مبيعات ومشتريات 60 يوماً). من **الإعدادات** يمكن إعادة البيانات التجريبية أو **بدء منشأة جديدة** بمسحها.

## الوحدات — Modules

| المجال | المحتوى |
|---|---|
| **نقطة البيع** | بحث بالاسم/الكود ومسح الباركود (Enter)، مجموعات الأصناف، سلة مع تعديل الكميات، خصم، دفع نقدي/بطاقة/تحويل/آجل، حساب الباقي، منع البيع بدون رصيد، تنبيه تجاوز حد الائتمان، طباعة إيصال 80مم أو فاتورة A4. اختصارات: F2 بحث، F9 إتمام البيع |
| **المبيعات** | فواتير المبيعات والمرتجعات (مع منع إرجاع أكثر من المباع)، حالة السداد، فلترة بالفترة والعميل وطريقة الدفع |
| **العملاء** | الأرصدة وحدود الائتمان، **كشف حساب** بالرصيد التراكمي، سندات القبض |
| **المشتريات** | فواتير الشراء والمرتجعات، **متوسط التكلفة المرجح** تلقائياً، طلب شراء تلقائي للنواقص |
| **الموردون** | المستحقات، كشف الحساب، سندات الصرف |
| **المخزون** | الأصناف (كود، باركود، وحدة، تكلفة، سعر بيع وجملة، حد الطلب)، الرصيد اللحظي، تنبيهات النواقص، بطاقة الصنف بكل الحركات، تسويات الجرد والتالف |
| **المالية** | الخزينة والمصرف بكل الحركات والرصيد الجاري، المصروفات حسب البند، حركات الإيداع والسحب |
| **التقارير** | قائمة الدخل (المبيعات، تكلفة البضاعة، مجمل وصافي الربح)، حركة المبيعات، المبيعات حسب المجموعة، الأصناف الأكثر مبيعاً وربحيتها، طرق الدفع، المصروفات، أرصدة العملاء، تقييم المخزون — مع تصدير CSV |
| **الفواتير بالإنجليزية** | لغة الطباعة: عربي، أو إنجليزي، أو ثنائي اللغة (عربي + إنجليزي) للفواتير والإيصالات والسندات وكشوف الحساب — مستقلة عن لغة الواجهة، ويمكن اختيارها لكل فاتورة على حدة، مع تذييل إيصال ورمز عملة بالإنجليزية (LYD) |
| **النظام** | المستخدمون والصلاحيات حسب الدور، بيانات المنشأة، العملة والخانات العشرية (3 للدينار)، الضريبة (0% افتراضياً)، النسخ الاحتياطي والاستعادة |

## بناء مثبّت ويندوز — Building the Windows installer

```bash
cd desktop
npm install
npm run dist          # على Linux/macOS بدون Wine → dist/Dalala-Commerce-Setup-<version>.exe
npm start             # تشغيل نسخة سطح المكتب للتجربة
```

## التقنية — Tech

HTML + CSS + JavaScript بدون أطر عمل ولا خطوة بناء. البيانات في `localStorage` (في نسخة ويندوز داخل `%APPDATA%\Dalala Commerce`). خط Cairo مضمّن (SIL OFL).

```
index.html · css/ · assets/
js/i18n.js     الترجمة
js/core.js     أدوات الواجهة + المنطق التجاري (المخزون، الأرصدة، الخزينة، الأرباح)
js/store.js    التخزين والبيانات التجريبية
js/crud.js     محرك الجداول والنماذج
js/entities.js تعريف الكيانات
js/pages.js    نقطة البيع، الفواتير، الكشوف، التقارير…
js/app.js      التنقل والصلاحيات والأحداث
desktop/       نسخة Electron + مثبّت NSIS
```

> هذا الإصدار يعمل على جهاز واحد. للعمل بعدة أجهزة في نفس الوقت (عدة كاشيرات) يلزم ربطه بخادم وقاعدة بيانات مركزية.
