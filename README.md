# منظومة دلالة التجارية — Dalala Commerce

منظومة حديثة لإدارة المحلات والشركات التجارية: **نقطة بيع، مخزون، مشتريات، حسابات العملاء والموردين، خزينة، مصروفات وتقارير أرباح** — بواجهة عربية/إنجليزية، متوافقة مع ليبيا (الدينار الليبي، السجل التجاري، الرقم الضريبي، الغرفة التجارية)، وتعمل بدون إنترنت على ويندوز أو المتصفح.

A modern, bilingual (Arabic / English) point of sale, inventory and accounting system for shops and trading companies, set up for Libya.

## التشغيل — Getting started

- **ويندوز:** شغّل `Dalala-Commerce-Setup-<version>.exe` (يُبنى تلقائياً عبر GitHub Actions، أو محلياً — انظر أدناه).
- **المتصفح:** افتح `index.html` أو شغّل خادماً محلياً: `python3 -m http.server 8080`

| الدور / Role | اسم المستخدم | كلمة المرور |
|---|---|---|
| مدير النظام / Admin | `admin` | `admin123` |
| كاشير / Cashier | `cashier` | `cashier123` |
| محاسب / Accountant | `accountant` | `acc123` |
| أمين مخزن / Storekeeper | `store` | `store123` |

عند أول تشغيل تختار: **منشأة جديدة فارغة** (تنشئ حساب المدير بكلمة مرورك) أو **بيانات تجريبية** للتجربة (الحسابات أعلاه). تبدأ البيانات التجريبية ببيانات واقعية (37 صنفاً، 10 عملاء، 6 موردين، مبيعات ومشتريات 60 يوماً). من **الإعدادات** يمكن إعادة البيانات التجريبية أو **بدء منشأة جديدة** بمسحها.

## الوحدات — Modules

| المجال | المحتوى |
|---|---|

| **المبيعات** | فواتير المبيعات والمرتجعات (مع منع إرجاع أكثر من المباع)، حالة السداد، فلترة بالفترة والعميل وطريقة الدفع |
| **العملاء** | الأرصدة وحدود الائتمان، **كشف حساب** بالرصيد التراكمي، سندات القبض |
| **المشتريات** | فواتير الشراء والمرتجعات، **متوسط التكلفة المرجح** تلقائياً، طلب شراء تلقائي للنواقص |
| **الموردون** | المستحقات، كشف الحساب، سندات الصرف |
| **المخزون** | الأصناف (كود، باركود، وحدة، تكلفة، سعر بيع وجملة، حد الطلب)، الرصيد اللحظي، تنبيهات النواقص، بطاقة الصنف بكل الحركات، تسويات الجرد والتالف |
| **المالية** | الخزينة والمصرف بكل الحركات والرصيد الجاري، المصروفات حسب البند، حركات الإيداع والسحب |
| **التقارير** | قائمة الدخل (المبيعات، تكلفة البضاعة، مجمل وصافي الربح)، حركة المبيعات، المبيعات حسب المجموعة، الأصناف الأكثر مبيعاً وربحيتها، طرق الدفع، المصروفات، أرصدة العملاء، تقييم المخزون — مع تصدير CSV |
| **الفواتير بالإنجليزية** | لغة الطباعة: عربي، أو إنجليزي، أو ثنائي اللغة (عربي + إنجليزي) للفواتير والإيصالات والسندات وكشوف الحساب — مستقلة عن لغة الواجهة، ويمكن اختيارها لكل فاتورة على حدة، مع تذييل إيصال ورمز عملة بالإنجليزية (LYD) |
| **مراسلة العملاء (واتساب)** | تذكير بالديون، إرسال الفاتورة، إرسال كشف الحساب، وعروض ورسائل عامة — برسائل جاهزة قابلة للتعديل (عربي/إنجليزي حسب لغة الطباعة)، وإرسال متتابع لكل العملاء المدينين، وسجل للرسائل. يعمل عبر روابط واتساب المجانية (wa.me) دون حساب WhatsApp Business API |
| **الصلاحية والجرد** | تواريخ الصلاحية لكل سطر شراء، دفعات تُصرف الأقدم صلاحية أولاً، تنبيهات المنتهي وما ينتهي قريباً، منع بيع المنتهي وشطبه، جرد فعلي بورقة جرد وترحيل الفروقات |
| **قصاصات الباركود** | Code 128 أو QR (يدعم العربية) مع اسم الصنف والسعر، لطابعة القصاصات (رول) أو ورق A4 ستيكرز (21/24/40/65) |
| **نقطة البيع (إضافات)** | فواتير معلّقة (F8 / F4)، عميل جديد من داخل البيع، تعديل الفواتير السابقة بصلاحية، اسم الكاشير على الإيصال |
| **الأمان** | إعداد أول بدون كلمات مرور افتراضية، تشفير كلمات المرور (PBKDF2)، إيقاف الدخول 5 دقائق بعد 5 محاولات، قفل المنظومة Ctrl+L وقفل تلقائي، صلاحيات لكل مستخدم (خصم، تغيير السعر، المرتجعات، تعديل الفواتير…) |
| **السنة المالية** | بدء سنة جديدة بتصفير الحركات وترحيل أرصدة المخزون والعملاء والموردين والخزينة، مع نسخة احتياطية تلقائية |
| **النظام** | المستخدمون والصلاحيات حسب الدور، بيانات المنشأة، العملة والخانات العشرية (3 للدينار)، الضريبة (0% افتراضياً)، النسخ الاحتياطي والاستعادة |

## الإصدار 2.3 — Print & export designs

- **فاتورة A4 جديدة:** رأس بشعار وبيانات المنشأة، رقم الفاتورة بارز، بطاقتا العميل والتفاصيل، جدول ملوّن بصفوف متبادلة، صندوق الإجماليات، رمز QR، التوقيعات.
- **الإيصال الحراري:** تصميم أوضح (عنوان مقلوب، كل صنف بسطرين، صندوق الإجمالي، باركود رقم الفاتورة). **يُطبع شريطاً واحداً متصلاً مهما كثرت الأصناف** — طول الصفحة يُحسب من محتوى الإيصال فلا تنقسم الورقة. يدعم ورق 80 و58 مم (من إعدادات الطباعة لكل جهاز).
- **سندات القبض والصرف:** صندوق المبلغ بارز وجدول الفواتير المسددة.
- **Excel منسّق:** اسم المنشأة وعنوان التقرير والتاريخ أعلى الورقة، رأس جدول ملوّن، صفوف متبادلة الألوان، صف إجماليات، أرقام بتنسيق العملة، تجميد الرأس، وإعداد طباعة يلائم عرض الصفحة.

## الإصدار 2.2 — What's new in 2.2

- **سداد الديون:** زر «سداد دين» في العملاء والموردين والفواتير. يُوزَّع المبلغ على أقدم الفواتير (أو على الفاتورة المختارة أولاً) ويُطبع إيصال سداد يذكر الفواتير المسددة. حالة الفاتورة والمتبقي يحسبان السندات. فلتر «عليها دين».
- **السجلات:** سجل المرتجعات، سجل الديون المسددة، سجل تسويات المخزون، سجل الإقفالات — بحث وفترة وطباعة وتصدير Excel و Word.
- **الحسابات:** دفتر قيود مزدوجة (مدين/دائن) يُولَّد من كل العمليات، وميزان مراجعة بأسماء مفهومة واتجاه الرصيد وتنبيه التوازن.
- **الجرد والإقفال:** لا بيع ولا شراء ولا تسوية أثناء جرد مفتوح. إقفال سنوي يحفظ أرصدة المخزون والذمم والصندوق والبنك.
- **نقطة البيع:** أزرار أصناف سريعة قابلة للتعديل (للأصناف بلا باركود)، زر «كامل»، شريط فواتير اليوم للعرض والتعديل، حد 500 سطر، بادئة رقم الفاتورة من الإعدادات.
- **قارئ الباركود بدون Enter:** في نقطة البيع وفاتورة البيع والشراء والمرتجع، يُضاف الصنف فور مسحه. الكتابة اليدوية تبقى تحتاج Enter حتى لا يُضاف صنف خطأ أثناء الكتابة.
- **فاتورة الشراء:** أزرار − و+ لكل سطر، تاريخ الصلاحية قبل إضافة الصنف (ودمج السطر المكرر بنفس الصلاحية)، مورد/عميل جديد من داخل الفاتورة، أعمدة المرتجع والصافي والمسترد. المرتجع بمسح الباركود.
- **الطباعة:** اختيار طابعة الإيصالات وطابعة A4 وطابعة القصاصات لكل جهاز، طباعة مباشرة دون نافذة، طباعة تلقائية بعد البيع أو فتح الفاتورة.
- **الصلاحيات:** 15 صلاحية منفصلة (عرض/إنشاء الفواتير، التحصيل، عرض المخزون، تعديل الأصناف، التسوية، المالية، إرجاع المشتريات…).
- **النسخ التلقائية:** نسخة يومية على الجهاز (آخر 30 يوماً) ونسخة قبل الاستعادة وقبل بدء سنة جديدة، مع قائمة للاستعادة.
- **التصدير:** ملفات Excel (.xlsx) منسّقة و Word (.docx) من كل القوائم والتقارير، وتقرير Excel شامل (ملخص، أيام، فواتير وأرباح، أصناف).
- **حذف صنف:** لا يُحذف صنف له رصيد؛ الصنف المستخدم في فواتير يُخفى ويبقى اسمه في الفواتير القديمة، ولا يمكن إرجاعه. رسالة الباركود المكرر تذكر اسم الصنف.

## التشغيل على عدة أجهزة — Several computers, one database

- **الجهاز الرئيسي:** الإعدادات ← «التشغيل على عدة أجهزة» ← جهاز رئيسي ← حفظ وإعادة التشغيل. تظهر بعدها عنوان الجهاز (IP) و**مفتاح الربط**. عند أول تشغيل يطلب ويندوز السماح للبرنامج بالشبكة — اختر «الشبكات الخاصة» ثم «سماح».
- **كل جهاز فرعي:** الإعدادات ← جهاز فرعي ← أدخل عنوان الجهاز الرئيسي ومفتاح الربط ← اختبار الاتصال ← حفظ وإعادة التشغيل.
- تُرسل كل عملية حفظ السجلات المتغيّرة فقط، وتصل تعديلات الأجهزة الأخرى خلال ثانية تقريباً. أرقام الفواتير والأكواد تُوحَّد على الجهاز الرئيسي فلا تتكرر.
- إذا انقطعت الشبكة يواصل الجهاز الفرعي العمل وتُحفظ العمليات في طابور وتُرسل تلقائياً عند عودة الاتصال.
- قاعدة البيانات المشتركة: `%APPDATA%\Dalala Commerce\shared\shared-db.json` على الجهاز الرئيسي، مع نسخة احتياطية يومية (آخر 30 يوماً) في `shared\backups`.
- كل جهاز يحتاج مفتاح تفعيل خاص به. المنفذ الافتراضي 47630 (TCP).

On the main computer choose **Main computer (server)**; on the others choose **Branch computer** and enter the main computer's IP and pairing key. Changes are synced record by record over the LAN (long-polling), document numbers are made unique on the server, and a branch keeps working offline with a queue that resends on reconnect.

## بناء مثبّت ويندوز — Building the Windows installer

```bash
cd desktop
npm install
npm run dist          # على Linux/macOS بدون Wine → dist/Dalala-Commerce-Setup-<version>.exe
npm start             # تشغيل نسخة سطح المكتب للتجربة
```

## التقنية — Tech

HTML + CSS + JavaScript بدون أطر عمل ولا خطوة بناء. البيانات في `localStorage` (في نسخة ويندوز داخل `%APPDATA%\Dalala Commerce`). خط Cairo مضمّن (SIL OFL).

```
index.html · css/ · assets/
js/i18n.js     الترجمة
js/core.js     أدوات الواجهة + المنطق التجاري (المخزون، الأرصدة، الخزينة، الأرباح)
js/store.js    التخزين والبيانات التجريبية
js/crud.js     محرك الجداول والنماذج
js/entities.js تعريف الكيانات
js/pages.js    نقطة البيع، الفواتير، الكشوف، التقارير…
js/app.js      التنقل والصلاحيات والأحداث
desktop/       نسخة Electron + مثبّت NSIS
```

> هذا الإصدار يعمل على جهاز واحد. للعمل بعدة أجهزة في نفس الوقت (عدة كاشيرات) يلزم ربطه بخادم وقاعدة بيانات مركزية.
